About RetroDisk

RetroDisk 9.5

RetroDisk is a private file manager that lives entirely in your web browser, styled like a classic desktop. You can store, organise, preview, edit, encrypt and share files without an account, a server or an internet connection (once the page has loaded).

How it works

Files are saved in your browser's own storage on this device — the Origin Private File System where available, or IndexedDB as a fallback. Nothing is uploaded anywhere. Large files are cut into 5 MB chunks; text-like files are compressed, and any file can be encrypted with a password before it is written to disk.

Good to know

  • Your files belong to this browser on this device. They don't sync, and clearing the site's data erases them.
  • Forgotten passwords cannot be recovered. There is no reset.
  • Use Save ZIP regularly if you want a backup.

File management

  • Folders, breadcrumb navigation, Up button, list and grid views, sortable columns, live search
  • Upload files, upload whole folders (structure kept), or drag and drop files and folders in
  • Copy, cut and paste (including folders), drag items onto folders or breadcrumbs to move them
  • Rename, batch rename (numbered), colour tags, Quick Access pins
  • Trash with restore, empty trash, and permanent delete

Import & export

  • Extract ZIP archives into any folder
  • Save files to your device, or save files and folders as a ZIP
  • SHA-256 integrity check on every download

Privacy & security

  • Optional per-file password using AES-256-GCM encryption with a PBKDF2-derived key, plus an optional password hint
  • Read-once files that delete themselves after being opened or saved
  • Secure Shred overwrites a file's data before removing it (best effort)
  • Steganography: hide text inside a PNG image and extract it again
  • Everything stays on your device — no accounts, no tracking, no cloud

Preview & editing

  • Built-in viewer for images, video, audio (auto-plays the next track), PDF, source code with syntax highlighting, and Markdown
  • Edit text files in place; rotate images and save them back
  • Set any image as the window wallpaper

Tools

  • Find Duplicates — finds identical files and moves the extras to Trash
  • WebRTC Share — send files directly to another browser with no server, by exchanging two copy-and-paste codes
  • Live Memory and Disk usage graphs (bottom right)

Look & feel

  • Four themes: Default, Windows 98, Classic Mac and Dark Mode (your choice is remembered)
  • Fullscreen mode

1. Add files

Click Upload and pick files, click Upload Folder to bring in a whole folder, or simply drag and drop files or folders into the window. A small box appears asking whether to protect the upload with a password — choose Skip to store it normally.

2. Organise

  • New Folder creates a folder; double-click to open it.
  • Use the address bar breadcrumbs or the Up button to go back.
  • Right-click an item for rename, copy, cut, tag colour, pin to Quick Access and more.
  • Drag items onto a folder (or a breadcrumb) to move them. Hold Ctrl while clicking to select several.

3. Protect a file

In the upload box, type a password, optionally add a hint, and press Apply. Protected files show a small red lock and ask for the password whenever you open, save or copy them. Tick Self-destruct (Read Once) to delete the file after its first use.

4. Open and edit

Double-click a file to preview it. For text files press Edit, then Save. For images press Edit Image to rotate, then Save & Overwrite.

5. Get files back out

Select items and press Save to download files, or Save ZIP to download files and folders together. Selecting a folder and pressing Save also gives you a ZIP.

6. Delete and recover

Delete moves items to the Trash (press the red Trash button to look inside). There you can use File ▸ Restore from Trash, delete items permanently, or Empty Trash. File ▸ Secure Shred skips the Trash and wipes the data immediately.

7. Share with another computer (WebRTC)

  1. Both people open Tools ▸ WebRTC Share.
  2. Host: press 1. Create Offer and send the code that appears to the receiver (chat, email, anything).
  3. Receiver: paste it into the top box, press 2. Accept Offer, and send the new code back.
  4. Host: paste that into the top box and press 3. Apply Answer. The status line says “Peer connected”.
  5. Host closes the window, selects files, reopens it and presses Send Selected Files. They land in the receiver's current folder.

8. Make it yours

Use the View menu to switch themes or toggle grid/list. Right-click an image and choose Set as Wallpaper. Use Pin to Quick Access for shortcuts you use often.

Limits & things to remember

  • Encryption and integrity checks need a secure page — https:// or localhost. On a plain http:// address they are unavailable and the app will tell you.
  • Browsers cap how much a site may store. The Disk panel shows your quota.
  • Very large files are read into memory while being hashed or, on the IndexedDB fallback, stored, so extremely large files may be slow.
  • Secure Shred is best effort: browsers and SSDs can't guarantee that old data is physically erased.
  • Steganography needs an opaque PNG (no transparency). Longer text needs a bigger image.
  • Private/incognito windows usually erase everything when closed.
